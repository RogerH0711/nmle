隱私權政策

本站是個人製作的免費刷題網站，不放廣告、不販售或分享任何資料。以下是本站實際會記錄的資料，以及這些資料的用途。

不登入時

  • 作答紀錄、錯題複習進度、好感度、設定等都只存在你這台裝置的瀏覽器（localStorage），不會上傳。清除瀏覽器資料就會消失。
  • 匿名使用統計：每台裝置每天一筆，內容是一個隨機產生的裝置代碼、當天作答幾題、有沒有開角色模式、有沒有登入、網站版本。不含帳號、Email 或作答內容，用來知道大約有多少人在用。
  • 回報疑義：你按「回報疑義」送出時，會記錄題目編號、回報原因、你寫的補充說明、你選的答案、網站版本和裝置代碼。補充說明請不要寫個人資料。

用 Google 登入時

  • 登入由 Google 與 Supabase（資料庫代管服務）處理。本站會收到 Google 提供的 Email、名稱與大頭貼網址，存在 Supabase 的帳號資料中，只用來辨識你的帳號，不會顯示給其他使用者。
  • 登入後，作答紀錄、模擬考作答、送出的禮物和你的暱稱會存到資料庫，讓你在不同裝置之間同步。
  • 回報疑義會連到你的帳號，方便處理；匿名使用統計仍然不會連到你的帳號。
  • 排行榜只顯示暱稱和成績統計（正確率、連續天數、模擬考分數），其他使用者看不到你的 Email、名稱或每一題的作答。暱稱預設是「同學」加四個數字，請不要改成真名。

誰看得到這些資料

  • 資料庫設定為每個人只能讀寫自己的資料。回報疑義與使用統計，任何使用者都讀不到。
  • 網站維護者可以在 Supabase 的管理介面看到資料庫內容，只用來處理回報、修正題目與了解使用量。

第三方服務

  • GitHub Pages：網站架在 GitHub Pages，GitHub 可能依其政策記錄連線紀錄（例如 IP 位址）。
  • Supabase：存放登入帳號與上述資料。
  • Google：提供登入。
  • 問 AI：按下 ChatGPT、Claude 或 Gemini 按鈕時，會開啟該網站並帶入題目內容。之後的對話由該網站處理，適用它們的隱私權政策；本站不會把資料送給這些服務。

本站沒有使用追蹤用的 Cookie 或廣告、分析工具。瀏覽器儲存空間只用來保存你的紀錄、設定和登入狀態。

保存與刪除

  • 資料在網站營運期間保存。網站停止營運時會刪除資料庫。
  • 登入後點右上角的暱稱，再按「刪除帳號」，就能自己刪除帳號與雲端上所有的作答紀錄、模擬考、禮物和暱稱，這台裝置上這個帳號的紀錄也會一起清掉，無法復原。回報疑義會保留題目相關的內容，但不再連到你的帳號。
  • 不登入時的紀錄只在你的瀏覽器裡，清除網站資料即可刪除。

聯絡方式

對隱私權有任何問題，請到 GitHub Issues 留言，或用網站上的「回報疑義」說明。

政策變更

政策內容有變更時會更新本頁，並修改上方的「最後更新」日期。

使用條款

  • 本站免費、非官方，與考選部或任何學校、補習班沒有關係。使用本站即表示同意以下條款。
  • 題目與答案：試題取自考選部公開的歷屆試題，由程式從 PDF 解析，可能有錯字、缺圖或解析錯誤。正解以考選部公告（含更正答案）為準。
  • 詳解：詳解由 AI 生成，沒有經過人工審核。雖然有和學生編寫的參考詳解比對結論、檢查名詞，並標示比對結果，仍可能有錯，和課本或官方答案不同時以課本與考選部為準。
  • 本站內容只供考試練習，不是醫療建議，也不能取代正式教材。
  • 角色與劇情：角色、劇情皆為虛構，所有角色都是成年人。立繪由 AI 生成。
  • 使用規範：請不要用程式大量送出作答、回報或其他請求，也不要使用冒犯他人或冒用他人身分的暱稱。違反時本站可以刪除相關紀錄、暱稱或帳號。
  • 本站依現狀提供，不保證服務不中斷或內容完全正確。對使用本站造成的任何損失（包含考試結果），本站不負責任。
  • 本站可以隨時修改功能、條款或停止服務，條款修改時會更新本頁。

出處與授權

  • 試題與答案：考選部公開之醫師第一階段考試歷屆試題（依著作權法第 9 條，考試試題不得為著作權之標的）。
  • 名詞對照：參考國家教育研究院「樂詞網」學術名詞，依政府資料開放授權條款第 1 版使用。
